# 吹田市救援物資配送支援システム — V2 計算改善版

本版は、既存の `suita_delivery_support(2).zip` を基に作成した改善版です。**P1、画面、避難所データ、地図、ローリング方式の実績反映処理は維持**し、P0・P2の計算機能を補強しています。

## 主な変更点

| 対象 | 変更内容 | 対象ファイル |
|---|---|---|
| P0 | 大規模な車両・配送回割当問題で計算が長引く場合、制約を確認した実行可能な初期案を作成し、物資量を整数混合計画法で再最適化 | `p0_kit_optimizer.py`、`p0_v2_refinement.py` |
| P0 | 訪問先・車両・配送回を固定した状態で、在庫・需要・積載容量・最小配送量・保守的な時間上限を再確認し、改善したF1・ηの上界を採用 | 同上 |
| P2 | 遺伝的アルゴリズムおよび2-optによる改善に加え、同じ拠点・同じ配送回の車両間で訪問先の移動と交換を探索 | `p2_kit_optimizer.py`、`p2_v2_routing.py` |
| P2 | 1車両の訪問先が7か所以下の場合は、Held–Karp法によってその車両の訪問順序を厳密に計算。ただし車両割当全体の最適性は保証しない | `p2_v2_routing.py` |
| 表示 | 保存済み結果の版番号を83に更新し、旧形式の結果の誤使用を防止。P0の再最適化に関する説明を修正 | `templates/plan.html`、`templates/routes.html`、`templates/p0.html`、`static/p0_dashboard_v69.js` |
| 検証 | 自動回帰テストを7件追加 | `tests/test_v2.py` |

**重要：** 大規模なP0では車両割当全体の最適解を証明していません。画面のηは、検証済みの実行可能解から求めた**上界**です。論文で定義した理論的な最小値η*が確定したわけではありません。

## 起動方法

1. ZIPファイルを展開し、`suita_delivery_support` フォルダーを開きます。
2. Pythonの仮想環境で `pip install -r requirements.txt` を実行し、必要なライブラリをインストールします。
3. 開発環境では `python app.py` で起動します。サーバーへの公開時は、既存の `gunicorn.conf.py` とRenderの設定を使用します。
4. GitHubの既存リポジトリに反映する前に、データとソースコードをバックアップしてください。
5. 計算結果の版番号が82から83に変わっているため、**P1 → P0 → P2を順に再計算**してください。以前ブラウザに保存したP0・P2の結果は再利用しません。

自動テストの実行：`python -m unittest discover -s tests -v`

## 実データを用いた検証条件と結果

- 避難所123か所のうち、備蓄量による対象条件を満たす100か所を使用。そのうち追加配送が可能な避難所は97か所。
- 仮定した初期条件：1,777人日分（7,996.5kg）、希求水準80%、ρ＝0.001、最小配送量3人日分（13.5kg）、最大5回。
- 車両は2t車10台、4t車8台。北部・南部の在庫はそれぞれ889・888人日分。1回の時間上限360分、累積時間上限1,080分。
- 走行時間には**市街地距離÷20km/hの推定値**を使用。Googleの実道路時間は使用していません。

## 今後の確認・改善事項

1. **F2・F3の多目的探索：** 論文の厳密なパレート最適化ではなく、限定した候補からF2を優先して選びます。Δの変更による公平性と早期供給の比較は別途必要です。
2. **ηの最適性証明：** 大規模な事例では全車両割当を含む整数混合計画の最適性を証明していません。上界と下界を区別してください。
3. **実道路・道路被害：** Google実道路時間と迂回経路の実際の取得は今回未検証です。「緊急交通路優先」機能は未実装です。
4. **近接避難所の代表点：** 今回の数値検証は100か所を個別に訪問する条件です。80地点への集約時には、代表点から各避難所までの引き渡し手順と荷卸し時間を確認してください。
5. **ローリング方式：** 小規模な実績確定テストは実施しましたが、需要・道路被害が変化する複数回の連続試験は未実施です。
6. **ウェブ画面：** Python・JavaScript・Jinjaテンプレートの構文は確認済みです。ただし検証環境にFlaskがなかったため、HTTPによる画面動作とRenderでの公開状態は未確認です。
