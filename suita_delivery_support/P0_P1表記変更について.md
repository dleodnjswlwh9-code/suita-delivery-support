# P0・P1の表記変更（2026年11月13日）

本版では、計算方法を変えず、旧版のP1とP0の記号・識別子を入れ替えました。

| 新しい記号 | 役割 | 旧版の記号 | 表示・処理 |
|---|---|---|---|
| P0 | 理想配分の計算（配送の運用制約を本格的に考慮する前の基準配分） | P1 | 配分計画、F1* |
| P1 | 拠点在庫・車両・配送回数・積込・時間などを考慮した実行可能配分の計算 | P0 | 配送・積込条件、F1、η |
| P2 | 実行可能配分を基にした配送経路の計算 | P2 | 物資輸送経路、F2、F3 |

計算の順序は **P0 → P1 → P2** です。評価指標の **F1*、F1、η＝F1−F1*** は変えていません。P1の大規模ケースで全体最適性を証明していない点も従来どおりです。

変更対象は、画面表示、入力案内、エラーメッセージ、Pythonのモジュール・関数名、JavaScript識別子、API経路、ブラウザ内の保存キー、関連資料です。新APIの主な経路は `/api/p0-kits`（理想配分）、`/api/p1-job`（実行可能配分）、`/api/p2-kits`（経路計算）です。運用条件・在庫・需要・評価式・計算アルゴリズムは変更していません。

既存ブラウザの旧版計算結果との混在を防ぐため、配分計画の形式識別子を更新しました。更新後は配分計画（P0）から計算し直してください。避難所の台帳やExcelの中身は変更していません。

補足として、配送先・災害条件画面と経路画面で、保存されたP1計算結果の版番号を誤って82と判定していた2か所を、現行計算エンジンの版番号83に修正しました。

検証：小規模4避難所におけるP0・P1・P2のF1*、F1、η、配送量、配送時間は名称変更前と一致しています。自動テスト・JavaScript構文・Jinjaテンプレート構文を確認しています。FlaskのHTTP実行と公開環境でのブラウザ操作は未検証です。
