# v43 — P2 선택 차량 피난소 필터 + Google 실시간 교통 예측

## 1. 지도와 피난소 목록 필터
- `全配送回 + すべての車両`: 전체 피난소 100개와 해당하는 모든 배송경로 표시.
- `第1回 + 1号車`: **제1회 1호차의 방문 피난소만**, 해당 차량의 거점과 실제 도로경로만 표시. 다른 차량의 피난소 마커는 숨김.
- `第1回 + すべての車両`: 제1회 방문 피난소의 마커와 제1회 경로만 표시.
- 하단 피난소 표도 동일하게 선택한 차량/회차의 방문 피난소만 표시. `表示中の車両・配送回の配送量`은 선택한 차량/회차에 실리는 수량임.
- 초록색 6px 고정 반경 원 안 비율은 **선택 회차 종료 시의 전체 차량 누적 충족률**이므로, 선택된 차량의 배송률과 혼동하지 않도록 설명을 넣음.
- Google 지도를 못 읽는 경우의 **개략 SVG 지도**에도 같은 필터가 적용됨.

## 2. 실시간 교통 반영
- Google Maps JavaScript Routes Library `Route.computeRoutes`를 사용하며 `travelMode:'DRIVING'`, `routingPreference:'TRAFFIC_AWARE'` 지정.
- 기존 P2의 방문순서는 변경하지 않고, 해당 방문순서의 **Google 실제 도로 경로** 및 **교통정보 반영 주행시간 `durationMillis`**을 받아옴.
- 차량 출동별 총시간 = Google 교통 반영 주행시간(분) + 30분 적재 + 방문소당 15분 반입 준비 + 1人日分당 0.04분 하역.
- F2 = 모든 배송회차에서 **해당 회차 가장 긴 차량 총시간**을 합산.
- 모든 차량 경로에서 교통 주행시간을 정상 수신하면 `配送完了予定時間（F2）`과 각 차량 카드 시간을 교통 예측값으로 변경하고, 화면에 `Google実道路＋交通情報を反映`을 표시. 결과 화면에도 출처와 함께 교통 예측 F2/차량별 시간을 표시하며, **10분을 초과한 데이터는 잠정 계산값으로 돌림**.
- 일부라도 Google 경로/교통시간 요청에 실패하면 F2는 기존 **맨해튼 거리÷20km/h 잠정값**을 유지하며, 교통 반영 완료라고 표시하지 않음. 통신 실패의 차량 시간은 잠정값으로 구분 표시.
- 경로는 화면에서 해당 차량 표시 시 요청되고, 같은 페이지의 동일 경로는 캐시를 재사용. `交通情報を更新`을 누르면 캐시를 지우고 현재 선택범위에 대해 다시 요청.
- Google `TrafficLayer`로 지도의 현시점 교통혼잡도(노선 정체 표시)를 보거나 체크를 꺼 숨길 수 있음. 이 오버레이의 화면갱신과 계산된 F2의 갱신은 별개임.
- **주의: 현행 GA 최적화와 거점/차량/회차 배정은 기존 맨해튼 거리/20km/h 기준을 유지함.** Google 교통정보는 기존 방문순서에 대한 **주행시간 평가 및 F2 화면 표시**에 적용됨. 따라서 '실시간 교통을 이용해 방문순서를 재최적화'했다고 주장하면 안 됨.
- 모든 회차를 **교통정보 조회 시점에 출발**하는 것으로 평가하므로 실제 2회차 이후 출발시각의 교통예측이나 재난 도로 봉쇄를 반영한 값이 아님. 최신 정보로 갱신하려면 사용자가 `交通情報を更新`을 사용해야 함.
- Google Routes의 `TRAFFIC_AWARE` 호출은 기본 경로조회보다 비용이 높을 수 있으며, 다수 차량/회차의 경로를 요청할 경우 호출수에 따라 과금됨. Google Cloud Console에서 예산/할당량 설정 권장.

## 3. 배포 설정
- Render 환경변수 `GOOGLE_MAPS_API_KEY`가 필요함.
- 해당 Google Cloud 프로젝트에 Maps JavaScript API와 Routes API 활성화 및 청구 계정 연결.
- API 키의 HTTP 리퍼러에 서비스 도메인을 허용, 두 API에 대한 키 제한 확인.
- v40의 `README_DEPLOY_KR.txt`에서 안내한 Root/Build/Start 설정을 동일하게 사용.
- 지도 위 `Google 道路経路 n/n件` 상태, `Google交通予測 n/n出動分取得` 상태를 확인.
- 실제 Google 서버 API 키가 없어 Google 클라우드 호출 성공 여부는 로컬에서 검증하지 못했음. 코드/요청 설정 및 모의 테스트는 검증함.
