# v44: P2 실제 도로경로 표시 및 우회 진단 개선

## 적용 범위
- **P2 물자수송경로**의 Google 지도와 차량 방문순서 표시를 개선했습니다. P1 배분 계산, 차량 수·적재량·물자량·배송 회차 설정은 변경하지 않았습니다.
- 차량 목록의 방문순서를 한 줄 말줄임 없이 끝까지 표시합니다. 차량 선택 시 지도 상단에서 출발 거점 → 방문 피난소 전부 → 복귀 거점을 번호와 함께 표시합니다.
- 출발 후 마지막 피난소까지 **빨간 실선**, 마지막 피난소에서 같은 거점으로 **파란 점선**, 각 경로에는 진행 화살표를 그립니다. 선에 흰 테두리를 추가했습니다.
- `全区間 / 配送（赤）/ 帰着（青）`로 경로 구간을 각각 표시할 수 있습니다.
- Google이 실제 도로를 따라 반환한 구간별 좌표(legs.path) 전체를 지도 범위에 포함합니다. `全経路を表示` 버튼으로 전체 범위를 복원할 수 있습니다.
- 차량을 선택했을 때 그 차량이 방문하는 피난소만 작은 초록 비율 마커로 표시합니다.

## 제1회 7호차 등 과도한 우회 개선
- 원래 P2 GA는 직각거리/20km/h를 사용해 피난소 방문순서를 정합니다. 실제 도로에서는 이 방문순서가 긴 우회를 만들 수 있습니다.
- 이제 **같은 차량에 배정된 피난소들**의 실제 Google 도로 경로를 요청할 때, 방문지가 2~25개면 `optimizeWaypointOrder` 옵션으로 실제 도로·교통시간 기준 방문순서를 다시 배열합니다. 차량·회차·배송량은 유지합니다. Google이 최적화에 실패하면 기존 GA 순서로 경로를 재요청합니다.
- 새 방문순서는 화면의 차량 카드, 상세 방문순서, 피난소 지도 번호에 동일하게 표시됩니다. 전체 차량의 교통 시간 취득에 성공하면 결과 화면의 방문순서와 F2에도 반영됩니다. 별도로 저장되는 Python P2 기준 결과는 변경하지 않습니다.
- Google이 제시한 도로거리가 매우 우회하는 구간은 `大きな迂回：要確認` 표시와 차량별 경고를 보여줍니다. 구간별 km/분으로 어느 구간의 문제가 큰지 확인할 수 있습니다.
- `高速・有料道路を避ける` 옵션으로 고속도로 진출입 때문에 생긴 우회를 비교할 수 있습니다. Google의 회피 옵션은 **선호 설정**이며 완전한 통행금지를 보장하지 않습니다. 선택 시 Google Routes API 재호출/추가 과금이 발생할 수 있습니다.

## 실시간 교통/주의
- Google Routes JavaScript Library `Route.computeRoutes`, `TRAFFIC_AWARE`를 사용합니다. 교통상황을 취득한 모든 출동의 F2는 교통예측 주행시간 + 기존 적재/반입/하역시간으로 계산됩니다. **최적화된 방문순서는 Google 지도 기준이며, Python의 GA 자체를 실제 도로시간 행렬로 교체한 것은 아닙니다.**
- 교통정보를 일부라도 받지 못하면 F2 전체는 기존 거리식(잠정)으로 표시합니다. 조회 시점의 교통상황은 재난으로 인한 도로 봉쇄를 재현하지 않습니다.
- Google Cloud의 Maps JavaScript API, Routes API, 키의 웹사이트 제한 및 청구 설정을 확인하세요. 실제 7호차 데이터의 우회 원인은 사용자의 브라우저 세션 결과와 Google 응답을 확인해야 확정할 수 있습니다.
- Render: ZIP 최상위 배포 방법 및 Start Command는 이전 버전과 동일합니다. Root Directory가 빈칸이면 `gunicorn --chdir suita_delivery_support app:app --bind 0.0.0.0:$PORT`.
