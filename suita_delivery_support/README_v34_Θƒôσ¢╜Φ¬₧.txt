2026-10-21 v34 — P1 1인 1일분 세트 + P2 배송 참고계획 + 배송 결과 화면

[중요]
이 버전은 기존 v33 프로그램을 기반으로 실제 P2 계산 API와 결과 UI를 추가했습니다.
교수님 논문의 F2/F3 및 필수 방문, 차량용량, 복수회 배송을 참고한 근사 구현이며
100개 피난소에 대해 전역최적임을 증명한 결과가 아닙니다.
P0는 사용자 요청대로 계산 기능이 보류되어 있고, η=0이 임시 적용됩니다.
P2에서 실현한 정수 세트 배송안의 F1값이 P1의 이상적인 F1*보다 나빠질 경우,
화면에 노란 경고로 '엄밀한 P2 조건을 충족하지 않는 참고 배송안'임을 표시합니다.

[사용 방법]
1. 배송계획에서 2t 트럭 대수, 최소 배송량(인분), 배송회차 상한을 저장합니다.
   현재 기본 입력값은 10대, 1인분, 8회이며 연구상 확정 수치는 아닙니다.
2. 배분계획에서 피난소 xlsx를 읽고, 수송거점 공급물자량을 'kg이 아닌 인분'으로 입력합니다.
   희구수준 70/80/90% 선택 후 P1 배분 계산을 실행합니다.
3. 물자수송경로 메뉴에서 'P2의 배송경로를 계산'을 선택합니다.
4. 배송시간, 방문 피난소 수, 총 배송량, 차량별 방문순서, 지도, 피난소별 충족률을 확인합니다.

[계산]
1인분 = 레토르트 밥 3식 + 생수 500mL 6병.
기존 초기 비축량에서 완전세트 인분만 계산하고 남는 낱개 식량·물은 별도로 유지합니다.
차량 적재: 2t / (세트당 가정중량 4.5kg) → 444인분.
시간: 도시직각거리 / 시속20km + 출동당 적재30분 + 피난소당 반입 준비15분 + 인분당 하역0.04분.
30분 적재시간은 최근 방재물류 사례에 기초한 연구 가정이지 2t 실측 평균 아님.
현재 지도는 각 방문 지점의 연결선이며 도로를 실제로 따라가지 않습니다.

[미구현 및 별도 확정 필요]
P0 η* 최적화, 실제 두 거점의 분리 재고, 실도로 최단시간, 24시간 재고·피난자 갱신,
긴급교통로 시나리오, 동일 회차 다중차량 적재시설 용량, 엄밀한 최적성 증명.
이 사항은 'P2_設計と未確定事項.md' 참조.
