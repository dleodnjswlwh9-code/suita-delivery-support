救援物資配分配送システム v37 — 物資輸送経路 UI 改善
====================================================

【今回変更した部分】
1. 既存ヘッダー、左メニュー、色、ページの基本構造は変更しない。
2. 物資輸送経路ページの「車両別配送計画」を上段中央に配置し、地図を下段の横幅全体に拡大した。
3. 全配送回・第1回・第2回… の選択ボタンを追加。選択回の経路・車両一覧に切り替わる。
4. 下部「選択した配送回の配分状況を表で確認」で、100避難所の回別・累積配送量、現時点確保量・充足率・訪問履歴を確認できる。
5. 地図の避難所を、既存の配分計画と同じ黒枠・紫色の充足率円で表示。
   円の大きさ＝必要量、紫色面積＝選択回終了時の（初期備蓄＋累計配送量）／必要量。
   全配送回を選択した場合は最終計画終了時点を表示する。
6. Google Maps の API キーが有効な場合は Google 地図上の円を重ねる。
   API キーが無い場合は移動時間評価とは独立した概略図に同等の円を表示する。

【計算値の出所／留意】
・各回の累計配送量は /api/p2-kits が返す「採用した参考配送案」の routes[].stops[].kits を足し合わせる。
・配送時間の最適化は従来のマンハッタン距離／仮定速度による。
  Google Directions の走行経路表示は最適化に使っていない。
・P0 は未実装、η=0 は仮定値。適合しない結果は参考配送案として警告を表示する。
・緊急交通路優先モードのアルゴリズムは未実装で、ボタンを無効化している。
・0～72時間の期間別在庫・需要更新も未実装。回別表示はP2の配送回であり24時間単位の期間ではない。
・二拠点の物資別在庫分割は確認されていない仮割当である。

【主なファイル】
・templates/routes.html : 表示レイアウト、選択回に応じた配分状態、地図オーバーレイ
・static/style.css : PC/モバイルの表示配置、紫色の円のデザイン

【動作確認】
・試験データ100避難所、計画8回・車両10台・最小配送量10人日分で、
  第1回と第2回の地図・累計配送量・表表示が変化することをブラウザ確認。
・1366/1920/390pxのブラウザ幅で横スクロールなし。
・Pythonの計算部分のテスト、JavaScript構文検査を実施。
・Google Maps実APIおよびFlask起動による一気通貫テストは、実行環境制約により未検証。
