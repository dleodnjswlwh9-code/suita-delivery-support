救援物資配送支援システム v18

主な変更点
1. ホーム画面
- 表示名を「救援物資配送支援システム」に統一
- 画面全体の余白を見直し、タイトル・メニュー文字を拡大
- 3つの主要機能を画面サイズに合わせて大きく表示

2. 配送計画の作成
- 地図は初期状態では避難所・輸送拠点マーカーを表示しない
- 避難所データ（Excel）を読み込むと、そのExcel内の緯度・経度を使って避難所を地図に表示
- 輸送拠点データ（Excel）を読み込むと、そのExcel内の緯度・経度を使って輸送拠点を地図に表示
- Excelを再選択すると、その種類のマーカーを新しいデータに置き換える
- マーカーをクリックすると施設情報・備蓄量を表示

Excel形式
避難所データ：名称 / 緯度 / 経度 / 収容可能人数 / 各備蓄量
輸送拠点データ：名称 / 緯度 / 経度 / 区分 / 各備蓄量
※ 1行目が大分類、2行目が備蓄量の項目名、3行目以降がデータ

Google API
- Maps JavaScript APIのみ使用
- Excelに緯度・経度が含まれるためGeocoding APIは不要

ローカル実行
1) PowerShell
   cd "C:\Users\이대원\Render\suita_delivery_support_v9"
2) APIキー
   $env:GOOGLE_MAPS_API_KEY="新しいAPIキー"
3) 起動
   & "C:\Users\이대원\AppData\Local\Python\pythoncore-3.14-64\python.exe" app.py
4) http://127.0.0.1:5000

Render

pip install -r requirements.txt

Start Command:
gunicorn app:app

Environment Variable:
GOOGLE_MAPS_API_KEY = Google Maps API key

注意:
地域（市）の補完線形は「地図表示用」です。将来、緊急交通路を使った所要時間計算を実装するときは、公式指定区間との最終照合を行ったうえで経路計算用線形として確定してください。

[v15 変更点]
- 左メニューを5項目に変更：ホーム / 配分計画 / 配送計画 / 物資輸送経路 / 結果の表示。
- 「配分計画」を独立画面として追加し、「配送計画」と分離。
- 配分対象物資はレトルトご飯と飲料水のみ。ライスクッキー等は配分計算に使用しない。
- 避難所データでレトルトご飯または飲料水500mlが0（または未入力）の避難所は配分対象から除外。
  現在の避難所データでは123か所中23か所を除外し、100か所が対象。
- 単位はkgに統一：レトルトご飯1食=0.5kg、飲料水500ml=0.5kg。
- 1人1日必要量：食料1.5kg、飲料水3.0kg。
- 現在避難者数の列がないため、v15では想定避難者数=収容可能人数×50%として必要量を算出。
- 食料と飲料水は別々に充足率を計算。
- 輸送拠点の在庫量の範囲内で、充足率の低い避難所から段階的に配分し、最低充足率を可能な限り高める。
- 配分結果は sessionStorage に保存し、配送計画画面へ引き継ぐ。
- 配送計画画面の名称から「作成」を削除し、ボタンを「配送計画を実行する」に変更。

[v16 変更点]
- v15の画面構成・配色・左メニューを維持したまま、配分計画を多期間配分に変更。
- 配分計画画面では「輸送拠点データ（Excel）」の読込を廃止。
- 避難所データ読込前は対象避難所数・除外避難所数を「-」表示。読込後に自動判定。
- レトルトご飯または飲料水500mlが0（未入力を含む）の避難所を配分対象から除外。
- 想定避難率を画面上で1〜100%の範囲で入力可能。
- 輸送拠点から各期に供給される物資量を画面上で直接入力。
  初期表示は1次（0〜24時間）、2次（24〜48時間）、3次（48〜72時間）。
  「＋ 配分回数を追加」で4次以降も追加可能。
- 各期について食料（レトルトご飯）kgと飲料水kgを別々に入力。
- 各期で充足率の低い避難所から段階的に配分し、最低充足率を可能な限り高める。
- 次期には「前期配分後の備蓄量－1日必要量」の残量を引き継いで再配分する。
  前期の未充足需要そのものは次期必要量へ加算しない。
- 配分結果表に各避難所の1次・2次・3次…の配分量を表示。
- 配送計画画面では配分回次を選択し、その回次の食料・飲料水配分総量を参照可能。

[v17 変更点]
- 配分結果の「1日必要量」を「必要量」、「初期備蓄量」を「備蓄量」に変更。
- 1次・2次・3次の間で1日分の消費量を差し引く処理を削除。
- 前回の配分後備蓄量を次回へそのまま引き継ぎ、追加物資を配分する累積方式へ変更。
  このため各避難所の充足率および最低充足率は、回次が進むほど低下しない。
- 配分結果を1次・2次・3次…のタブで個別表示。
- 各回次の表に「必要量 / 備蓄量 / 配分前充足率 / 当該回次配分量 / 配分後充足率」を表示。
- 充足率を「低い順 / 高い順」で並べ替える機能と避難所名順を追加。
- 各回次で「配分前最低充足率 → 配分後最低充足率」を表示。
