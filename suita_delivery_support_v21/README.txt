救援物資配送支援システム v21.3 — 避難所Excel 1ファイル版

【配分計画の使用方法】
1. 「配分計画」を開く。
2. 「避難所データ（Excel）」に「避難所データ(8).xlsx」のような地域・避難所名・緯度・経度・収容可能人数・備蓄量のあるファイルを選択する。
   Excelは1ファイルだけ。吹田市救援物資配分用基礎データ.xlsxの手動アップロードは不要。
3. 1次・2次・3次の食料・飲料水の輸送拠点物資量を入力し「配分計画を実行する」を押す。
4. 配分結果は表（初期表示）・グラフ・地図で切り替え、1次/2次/3次、食料/飲料水を選択する。

【内部資料】
data/regional_population.jsonに、吹田市の公式地域別「発災直後の避難所避難者数」と「在宅避難者相当数」を格納。
出典：吹田市「吹田市備蓄計画」（令和7年3月）, p.2–3 (https://www.city.suita.osaka.jp/_res/projects/default_project/_page_/001/004/261/bitikukeikakuR6.3.pdf)
公式計画上の在宅避難者相当数は食料支援のための20%加算であり、72時間内に3等分して入所するとの仮定は本研究のシナリオ。
公式数値に対し、ユーザー提供の吹田市救援物資配分用基礎データ.xlsxでは、
片山・岸部／豊津・江坂・南吹田、および山田・千里丘／千里ニュータウンの値が逆に記載されていたため、内部資料は公式値に修正。

【実装上の前提と留意事項】
地域別公式想定人数を、その地域の避難所の収容可能人数に比例配分する。
地域内で端数人数がある場合、総和が地域公式人数と一致するよう最大剰余法で調整。
在宅避難者相当数は追加入所の上限シナリオとし、1次・2次・3次の3回で可能な限り均等に到着。
避難所備蓄量のレトルトご飯と飲料水がともに正の値の施設が配分対象（現在の台帳は100施設）。
未整備23施設は配分分析から除外。ただし初期人口・追加人口推計には123施設を含める。
既存のローリング配分に従い、選択した期の需要量と在庫量から追加配分量を計算。
時間経過による食料・水の実際の消費は未控除。
Google Mapsは環境変数GOOGLE_MAPS_API_KEYが設定されているときに表示。地図上に輸送拠点は表示しない。

【起動】
pip install -r requirements.txt
python app.py
Render: gunicorn app:app


【v21.4 配送計画Excel互換性修正】
「配送計画」の避難所Excel読込方法を「配分計画」と統一しました。
・先頭シートだけではなくすべてのシートから避難所台帳を検出します。
・「地域」列を先頭に追加した形式、2段見出し、従来の地域列なし形式に対応します。
・各列は固定位置ではなく列見出しから判定します。
・同一ファイルを配分後に配送画面から再読込しても配分結果・各期人口を保持します。
・異なる避難所台帳を読込んだ場合は旧配分結果を無効化し、再実行を促します。
・輸送拠点・緊急交通路Excelの従来の形式と配送画面レイアウトは変更しません。
