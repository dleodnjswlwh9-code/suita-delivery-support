吹田市 救援物資配送支援システム v23.9 — 수정 내용

1. v23.8에서 독자적으로 추가한 ‘희구수준까지만 배분’ 제한과
   ‘목표 대비 부족률을 먼저 평준화’하는 다단계 최적화 규칙을 제거했습니다.
2. 교수님 원문 제4.2절 식 (24)~(31)의 F1 목적함수, 정규화,
   최대 미달도 제약, 배분 상한/하한, 재고/차량능력 제약을 반영했습니다.
3. 교수님 원문은 물자 1종/거점 1곳 가정입니다. 이 프로그램은
   식료품과 음료수의 F1을 각각 계산하되, 총 차량 운반능력을
   공유하도록 두 F1의 합을 최소화하는 2종 물자 확장입니다.
   따라서 두 물자 합산 F1 수치는 원문 1종 물자 F1*와 동일하지 않습니다.
4. 목표 공급률은 달성 목표이지 배분 상한이나 최저 보장률이 아닙니다.
   부족한 피난소가 2~3% 남거나 목표 80%를 넘겨 100%가 되는
   결과가 수학적으로 가능합니다. 수정본도 이를 임의로 금지하지 않습니다.
5. 配分結果에서 ‘ρの感度比較’를 펼치면 같은 조건으로 ρ를
   0.0001 / 0.001 / 0.01 및 사용자가 입력한 값으로 계산한
   최저 충족률과 목표 달성 피난소 수를 비교할 수 있습니다.
6. 비축량은 원본 Excel 그대로 읽습니다. 실제 배송을 완료한 양은
   P0/P2 이후 별도로 기록해야 합니다. P0/P2는 아직 미구현입니다.

실행: pip install -r requirements.txt → python app.py
