救援物資配送支援システム v23.5
===========================================
今回の変更：固定の1次・2次・3次配分計画を廃止。現在利用可能な食料・飲料水の
輸送拠点物資量のみを入力してP1を1回計算。配送能力条件の表題を簡略化し、
旧版の24時間ごとの配送回数に関する注記を削除しました。

【実行方法】
1. pip install -r requirements.txt
2. python app.py （Render の場合は gunicorn app:app）
3. 「配分計画」で以下のExcelをそれぞれ1回アップロード：
   ① sample_data/shelters.xlsx　② sample_data/aspiration_targets.xlsx
4. 「希求水準・調整係数」でρを設定します。
5. 「輸送拠点物資量の設定」で現在使用できる食料と飲料水の量をkgで入力します。
6. 「配送能力条件」で最小配送量δ、残りの配送回数、車両台数を入力します。
7. 「配分計画を実行する」を押します。P1の参考配分結果とF1*を表示します。
8. 「配送計画」の参考配分欄は現在計画1回分のみを表示します。

【モデルと前提】
- 教授モデル rev21 の P1 を、食料・飲料水2物資・共用車両容量へ拡張した
  線形計画として計算します。P0/P2および確定した実配送は未実装です。
- 配送能力条件の「残りの配送回数」は、現在から先に各車両が利用できる
  回数であり、24時間×3期間などの固定期間ではありません。
- この版の想定避難者数は、内部の6地域別「発災直後」の初期推計から各避難所に
  割り当てた人数です。未到着人員想定（6,445人）は保有するものの、
  1次・2次・3次への均等上乗せを廃止しました。実態の再観測・需要更新は
  P0/P2による実配送結果の記録とあわせて今後実装が必要です。
- 2拠点の車両・在庫を独立した制約として扱う実装は今後の課題です。
- このP1の「配分量」はあくまで予定配分です。実配送実績に計上しません。
- 最小配送量δの初期表示0.5kgは仮の入力例であり、研究での最終設定値ではありません。

【以前の利用環境からの移行】
- セッション保存の「allocationStages」から最初の物資量だけ引き継ぎます。
  2次・3次に入力済みの物資量は使用しません。
- 変更前の3期分の配分結果は引き継ぎません。新しい条件で再計算してください。
